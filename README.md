# 阅窗

一个使用自己模型接口的 Chrome 阅读助手，把侧栏对话、划词查阅、链接预览和资料整理放在浏览器里。当前版本 **0.14.3**，适合个人使用和小范围试用。

项目没有应用云端服务器。模型请求直达你选择的服务商，收藏和保存的研究报告留在本机。

[下载试用版本](https://github.com/Aurum9/yuechuang/releases) · [更新记录](CHANGELOG.md) · [反馈问题](https://github.com/Aurum9/yuechuang/issues)

## 能做什么

- **侧栏对话**：点击扩展图标打开，支持流式回答、多轮追问、Markdown、停止生成和回答详情。对话页打开时，网页新选区会成为输入框旁可移除的引用，可随下一条问题发送，也可直接点「翻译」或「解释」。划选一段话时，模型会推荐几个值得查的词，点词即可结合整段选区翻译并解释。没有网页选区时，「翻译」和「解释」会处理输入框里的文字。
- **划词翻译与解释**：选中文字后点击小浮窗，结合所在段落查阅；短英语可按需补充双语例句。回答完成后点击「追问」，可将原文和回答接到侧栏现有会话末尾。
- **链接预览与摘要**：拖动普通链接，在当前页预览目标网页；正文就绪后自动生成中文摘要。长文默认先确认分段计划。
- **词句收藏**：保存原文、解释、例句、语境与来源，支持搜索和 JSON / Markdown 导出。
- **跨页研究**：围绕问题读取你指定的 1—5 个链接，生成带原文引句和来源的比较报告，可手动保存或导出。

## 两种连接

| | 模型 API | ChatGPT 订阅（官方登录） |
| --- | --- | --- |
| 使用凭证 | 自己的服务商 API Key | 自己的 ChatGPT 账号及套餐用量授权 |
| 当前覆盖 | 侧栏对话、划词、摘要、跨页研究 | 侧栏对话、划词翻译、解释、例句和文章摘要 |
| 额外组件 | 无 | 无，直接在扩展中登录 |
| 用量归属 | 所填 API 接口对应的余额或额度 | 账号实际获准使用的套餐用量 |

API 模式支持兼容 Chat Completions 的流式文本接口，具体兼容性取决于服务商。官方订阅连接通过阅窗自身的授权流程登录，侧栏对话、划词查阅和文章摘要直接调用 OpenAI Responses API。侧栏对话会提供联网搜索工具，由模型按问题决定是否使用。

两种连接共用单次上下文预算，默认 64,000 tokens。已有配置可在「设置 → 模型 API 与预算」调整。侧栏对话默认预留最多 8,192 tokens，API 模式按剩余空间申请输出，订阅模式的实际输出上限由所选模型决定。

官方订阅的资格、模型列表和额度以账号实际授权为准。文章摘要跟随已保存的连接。跨页研究使用模型 API 配置。旧「ChatGPT 网页」模式已从 0.13.0 生产包移除。

## 安装试用

面向 **Windows / macOS + Chrome 120 或更新版本**，两端使用同一个扩展包，不需要本地助手或 PowerShell。当前采用开发者模式手动安装，尚未通过 Chrome 应用商店发布。自动化浏览器验证不代表两个系统都已完成真实账号人工验收。

准备对应版本的发行附件：

- `reading-assistant-0.14.3.zip`：所有人需要的扩展包。

1. 将扩展 ZIP 解压到固定目录，保留该目录。
2. 打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。源码构建则选择 `dist`。
3. 点击阅窗图标进入侧栏，在「设置」中选择连接。API 模式填写自己的接口地址、模型标识和 Key。
4. 使用官方订阅时，点击「使用 ChatGPT 登录」，在 OpenAI 页面登录并授权套餐用量。阅窗会自动保存订阅连接，更换订阅模型时也会自动保存。
5. 阅窗安装后可在 HTTP 和 HTTPS 网页上划词和预览。如果 Chrome 限制了网站访问，可在扩展详情中调整。在划词工具条的「×」中可暂时隐藏本页工具条，或永久隐藏当前网站。永久隐藏可在设置中恢复。

普通「保存连接」不调用模型；「保存并测试连接」会实际调用一次模型。更新时将新版完整解压到原扩展目录，点击扩展卡片「重新加载」，重开侧栏并刷新来源网页。当前没有自动更新。

安装前请阅读[安装与使用说明](docs/安装与使用说明.md)，每位使用者都使用自己的 Key 或账号。

## 开发与构建

需要 **Node.js 22.12+**。运行成品扩展无需 Node.js、Go 或 Python。

```powershell
npm ci
npx playwright install chromium
npm run build
npm test
```

构建输出在 `dist`。浏览器回归使用独立临时配置和模拟接口，不需要真实 Key 或用户现有浏览器资料：

```powershell
npm run test:context
npm run test:phrases
npm run test:research
npm run test:sidebar
npm run test:siwc-ui
npm run test:siwc-auth
```

`npm run test:e2e` 保留第一阶段预览与摘要回归；`test:webchat*` 保留旧网页连接的历史检查，不用于证明当前官方订阅连接可用。测试报告和截图输出到 `test-results`。

生成扩展 ZIP：

```powershell
npm run package
```

`helper/` 和 `scripts/helper-*` 保留为 0.10—0.13 版本的历史实现，当前扩展不连接、安装或分发助手。当前发行核验使用 `npm run verify:release` 检查扩展 ZIP 与对应版本测试证据，详见[纯扩展授权说明](docs/纯扩展授权方案.md)。

## 隐私与数据

- **发送给模型的内容**：聊天问题、随问题提交的网页选区引用和已完成历史；划词原文和邻近语境；主动总结或研究的网页正文。侧栏对话打开时，划选一段网页文字会自动将该选区发送给所配模型来推荐词语，推荐请求只包含选区，不含草稿或聊天历史。点击「追问」只将选区和查阅结果加入本机会话历史，后续发送问题时才会将它们作为历史传给模型。远程服务商自身的数据处理规则仍适用。
- **API Key**：默认仅存本次浏览器会话，勾选记住后存本机扩展存储；持久 Key 当前没有额外的应用层加密。Key 不进入网页内容脚本、导出或诊断。
- **官方授权凭证**：保存在当前浏览器的 `chrome.storage.local`，限制为扩展可信上下文访问；不云同步、不导出，当前没有操作系统钥匙串或额外应用层加密。登录中的 PKCE 事务存于 `chrome.storage.session`，可跨后台休眠恢复。官方请求使用 `store: false`，不自动同步 ChatGPT 官网历史或记忆。
- **聊天记录**：保存在 `chrome.storage.session`，可在同一浏览器会话重新打开查看，重启浏览器后清除。
- **收藏和报告**：明确保存后写入 `chrome.storage.local`，可导出；卸载扩展或清除扩展数据会丢失。

没有云同步、统计上报、统一账号或共享额度服务。请勿上传真实 Key、Token、授权回调链接、扩展凭证或整个 Chrome 用户目录。

## 当前限制

- AI 回答、翻译和引用可能有误，重要技术结论请核对原文。
- 优先读取已加载、可见、可访问的网页文章。Chrome 内部页、Web Store、PDF、图片正文、复杂编辑器及部分跨域嵌入不在当前读取范围。
- 网站的嵌入策略可能阻止预览，届时可在普通标签页打开。登录、付费墙、分页和折叠内容可能使读取范围不足。
- 跨页研究只访问你提供的链接；它不会自主搜索、继续遍历链接或填写表单。研究所属页面需要保持打开，侧栏内切换标签可继续运行。
- 请求失败或中断后不自动重发。多次调用、例句补充、连接测试与分段摘要可能产生额外用量，停止后的计费由服务商决定。
- 自动化覆盖使用隔离环境和模拟接口，无法替代真实账号、具体网站和 Chrome 原生交互的人工验证。
