# 阅窗：安装与使用说明

适用版本：0.14.2。更新日期：2026-11-10。

阅窗提供侧栏对话、划词翻译与解释、链接预览与摘要、词句收藏、跨页研究。当前以开发版方式小范围试用，安装和更新需要手动操作。

## 先准备哪些文件

请向提供者索取正式打包的文件：

- `reading-assistant-0.14.2.zip`：扩展，所有人都需要。

包内没有提供者的 API Key、ChatGPT 登录凭证或浏览器数据。每位使用者填写自己的接口与 Key，或登录自己的 ChatGPT 账号。本项目没有代充值、共享额度或统一账号服务。

Windows 和 macOS 使用同一个 Chrome 120+ 扩展包，无需安装本地助手、PowerShell、Node.js、Go 或 Python。其它浏览器尚未单独验收；自动化模拟验证不替代真实账号验收。

## 安装扩展

1. 将扩展 ZIP 解压到固定目录，Windows 例如 `D:\Apps\Yuechuang\extension`，Mac 可放到个人文稿目录。请保留这个目录。
2. 打开 Chrome 的 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。
4. 点击阅窗工具栏图标，打开侧栏，再进入「设置」。若图标被收起，可从 Chrome 的扩展菜单打开或固定。

这是加载可信开发代码的试用方式，扩展尚未通过 Chrome 应用商店发布和审核。Chrome 官方将未打包加载定位为开发用途；正式长期分发可以改走应用商店渠道。[Chrome 分发说明](https://developer.chrome.com/docs/extensions/how-to/distribute)

## 选择自己的连接方式

| 项目 | 模型 API | ChatGPT 订阅（官方登录） |
| --- | --- | --- |
| 凭证 | 自己的服务商 API Key | 自己的 ChatGPT 账号及套餐用量授权 |
| 额外安装 | 无 | 无 |
| 当前覆盖 | 侧栏对话、划词、摘要、跨页研究 | 侧栏对话、划词翻译、解释、例句和文章摘要 |
| 消耗 | 所填接口对应的 API 用量或余额 | 账号实际获准使用的套餐额度 |

侧栏对话、划词查阅和文章摘要跟随已保存的连接。跨页研究使用模型 API 配置。

### 使用模型 API

1. 在「对话、划词与摘要连接」选择「模型 API」，点击「保存连接」。
2. 在下方接口设置填写自己的 Base URL、模型标识和 API Key，然后保存。
3. 点击「保存并测试连接」会实际调用一次模型；普通保存连接不调用模型。

请使用自己信任的接口服务商。勾选保存 Key 后，Key 会保存在本机浏览器扩展存储中，当前没有额外的应用层加密；不勾选时仅保留在本次浏览器会话中。接口服务商的域名、模型名和费用以该服务商为准。

### 使用 ChatGPT 订阅

1. 在设置中选择「ChatGPT 订阅（官方登录）」，点击「使用 ChatGPT 登录」。
2. 在 OpenAI 页面完成账号登录和套餐用量授权。
3. 完成授权后，登录页会自动关闭。阅窗会保存订阅连接，沿用仍可用的已选模型，或选用授权列表中的第一个模型。更换模型时也会自动保存。
4. 切回对话发送简短问题，或在网页上选词并点击「翻译」，确认能收到完整回答。

每位朋友都需要在自己的浏览器中登录。不要发送自己的浏览器资料或扩展存储；ZIP 只包含程序代码。凭证保存在当前浏览器的扩展存储中，不云同步，没有系统钥匙串或额外应用层加密。共用电脑请在用完后「退出本机账号」。

从 0.13 或更早的助手版本升级，需要在扩展内重新登录；不会自动读取或迁移旧助手的凭证。旧助手不再被调用，可按[旧版卸载说明](本地助手安装使用.md)自行清理。

每个人的套餐资格、模型列表、额度和网络环境可能不同。「已登录」与「允许使用套餐用量」需要分别满足，最终以完整回答返回为准。官方授权会为用户自己的账号注册连接，无法通过复制别人的安装目录继承额度。[OpenAI Docs：官方登录与注册](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)

## 数据与使用范围

- 本项目没有云端存储服务。发送的问题、必要历史和主动读取的网页文字，会传给你选定的模型服务商；服务商自身的数据处理规则仍适用。
- 聊天记录保存在本次浏览器会话中，关闭侧栏后可再打开查看，重启浏览器后会清除。它不会自动出现在 ChatGPT 官网历史中，也不会读取官网记忆或历史聊天。
- 词句收藏和手动保存的研究报告留在本机，浏览器重启后仍在。重要资料可先导出；卸载扩展或清除扩展数据会造成丢失。
- 网页读取需要相应网站权限。普通对话不自动读取当前网页；划词发送选区及邻近语境，摘要和研究发送当前可读取的网页内容。
- 拖动新链接预览时，正文可读后会自动调用当前连接的模型生成摘要。长文需要多次调用时默认先确认分段计划。
- 划词重试、补充例句和研究会产生模型调用。跨页研究每个目标页一次分析，最后再汇总。
- AI 回答与摘要可能有误，技术结论和引用请结合原文核对。Chrome 内置页面、部分 PDF、图片文字和限制嵌入的网站可能无法读取或预览。

## 更新、卸载与反馈

当前没有自动更新。收到新版后，先停止任务、关闭侧栏，将新版完整解压到原来的扩展目录，再到扩展管理页点击「重新加载」，并刷新需要阅读的网页。尽量保持路径不变，避免 ID 变化；更新前可导出收藏和研究报告。

卸载前可先在阅窗设置「退出本机账号」，并在 ChatGPT 设置中检查应用授权。卸载扩展会删除当前扩展存储，但不能代替远端授权撤销。

反馈问题请提供：版本号、Chrome/操作系统版本、所选连接方式、操作步骤、错误文字；官方订阅问题可复制设置里的连接诊断。截图先遮住 Key、邮箱和私人内容。不要发送 Token、授权回调链接、`credentials.bin` 或整个 Chrome 用户目录。
