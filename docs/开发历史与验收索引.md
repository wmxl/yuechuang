## 安装与使用

分发试用时，可一并提供[安装与使用说明](安装与使用说明.md)。发行 ZIP 不包含个人配置；官方订阅连接需要每位使用者安装助手并完成自己的授权。

1. 使用 Chrome 120+，打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本项目的 `dist` 文件夹。ZIP 版本先解压，选择包含 `manifest.json` 的目录。已有安装点击扩展卡片的“重新加载”，再刷新来源网页。
3. 点击扩展图标，进入侧栏“设置”。使用 ChatGPT 订阅时，选择“侧栏对话连接 → ChatGPT 订阅（官方登录）”，复制当前扩展 ID 并按[说明安装本地助手](本地助手安装使用.md)。在插件中发起官方登录，亲自完成身份和套餐用量授权，再选择实际返回的模型并保存连接。已显示授权就绪时可直接发送；发生授权失效再重新登录。该连接无需填写 API Key。
4. 使用自己的模型 API 时，在“侧栏对话连接”选择“模型 API”，填写下方 Base URL、模型标识和 API Key，授权接口域并保存。`https://你的接口/v1` 会追加 `/chat/completions`，完整接口地址也可用。“保存并测试连接”会调用一次模型。摘要、划词和研究使用这组 API 配置。
5. 切回“对话”提问。官方订阅连接由插件直连 OpenAI；完成授权后可以关闭登录页。检查账号成功只证明登录和模型读取成功，需以完整回答验证实际对话能力。
6. 需要阅读网页时，在“设置”中授权来源网站、目标网站，或按需授权 HTTPS 网页访问。原生授权提示需要在自己的 Chrome 中操作；API 聊天需要接口域权限，官方订阅连接需要 `api.openai.com` 权限。
7. 在已授权网页拖动普通链接，移动超过 **28px** 即出现页内浮窗，无需松手或移动到指定位置。指针位于浮窗内时，来源页呈模糊效果；移出后恢复。正文就绪后自动生成流式摘要，支持停止、复制、收起、重新读取、在普通标签页打开和关闭预览。

拖动打开的目标自动尝试总结一次。浮窗内后续导航需要手动总结。

0.6.1 修复聊天快捷选项：预置内容可以相互切换；手动输入或修改文字后隐藏选项，清空后恢复。见 [本次验证](M5快捷选项修订验收.md)。

0.6.2 支持聊天回答的 Markdown 显示：标题、加粗、列表、引用、代码块、表格和链接。流式生成、停止后的片段与重开会话均使用相同渲染；复制和后续对话保留原始 Markdown。见 [本次验证](M5Markdown显示修订验收.md)。

0.9.0 曾使用“ChatGPT 账号（实验）”网页连接，复用官网页或创建后台固定代理标签，交互在侧栏完成。0.13.0 已移除这条连接；历史实现和试用记录仍保留在文档中。

官方订阅连接状态区分“已登录、模型已读取”和“对话成功”。只有一次回答完整返回，才显示最近对话成功。失败后保留阶段、HTTP 状态和固定分类。进入设置点击“复制连接诊断”即可反馈；内容不含账号、聊天正文或凭据。

## 侧边栏与直接对话

侧栏顶部有“对话／跨页研究／收藏／设置”四个标签。“对话”是新打开侧栏文档的默认页。设置、研究和收藏在首次访问时加载，切换标签会保留这些页面、未提交的草稿及当前研究；切换本身不调用模型。旧设置、研究和收藏页面仍可单独打开。

在对话输入框输入问题，点击“发送”或按 Enter；Shift + Enter 换行。回答流式显示，支持继续追问和复制。对话仅包含你输入的文字及已完成的历史消息，不会自动读取当前网页、收藏或研究报告，也不操作网页。聊天和研究可以各自运行，互相切换或发送聊天不会停止研究。

助手回答按 Markdown 排版，用户输入按原文展示。长代码与表格在自身区域内横向滚动；链接点击后另开标签，图片不自动加载。HTML 作为文字显示，危险协议和相对链接不提供可点击入口。不支持数学公式、图表或代码语法高亮。

点击“停止生成”中止当前请求并保留片段。停止或失败的这一轮不会作为完整上下文送入后续请求；后续提问继续沿用此前已完成的轮次。点击“新对话”后需确认，确认会清空整个当前会话，并停止当前回答。关闭发起对话的侧栏文档、断开连接、保存配置、清除 Key、撤销权限或开始连接测试会停止聊天，不自动重发。

0.10.3 为后台连接断开加入有限重连。恢复期间保留输入框草稿与已收到的内容，重新连接只获取当前状态；生成中的回答按中断处理，不自动续写。较短的旧检查点不会覆盖当前已见片段，额外保留的片段仅用于本地显示，不会作为已完成回答进入后续请求上下文。连续恢复失败时，点击「对话」或重新返回侧栏可再尝试，不必先清空草稿。关闭侧栏文档会清理重连计时器。

单条问题最多 6,000 个字符，一个会话最多 40 条消息（用户与助手各算一条，停止或失败的轮次也占用）。每次发送最多调用一次模型，完整历史、系统说明和 1,536 tokens 输出预留共同计入设置中的单次预算。超出预算或条数时提示清空会话或调整设置，不静默删减历史，也不自动付费重试。

插件当前聊天保存在 `chrome.storage.session.chatSession`，同一扩展会话下的侧栏共用一个当前会话；关闭页面后可在同一浏览器会话中重新查看，重启浏览器后清除。输入框草稿不持久保存；切换标签会保留当前文档中的草稿。插件没有聊天历史列表或聊天导出。

## 划词翻译与解释

在已授权的技术文章、外语文章或页内预览目标中完成文字选择，附近会出现紧凑操作条。点击“翻译”直接显示流式译文，点击“解释”说明选区在本文中的含义。工具条自动出现不产生模型调用，无需右键或再次确认。

短英语词语或短句的译文可按需补充“双语例句”，提供 1—2 组英文句及对应中文译文；解释的补充入口为“用法示例”，给出具体情境，适用时给最小代码。核心答案和示例分区展示。长段落直接完整翻译，隐藏不适用的例句入口。生成补充内容和重试各调用一次模型，均需明确点击，不自动增加调用。

支持停止、复制和关闭。更换选区、点击空白、滚动、关闭、页面导航或权限变化会清理旧界面和任务；操作条点击保持原选区。原生右键“结合本文解释”“翻译为中文”继续作为补充，Google 搜索与复制保留。

解释与翻译只发送选区、所在可见段落和少量相邻段落、标题及 URL，不读取整篇文章。选区最多 6,000 字符，上下文最多 10,000 字符；上下文过长时尝试选区附近的完整句，仍超限则提示重选。超过模型预算也会先提示，不静默裁剪选区。

输入框、编辑器、隐藏内容、扩展自身界面、PDF 与图片文字不参与本阶段选区读取。页面导航、撤销权限、保存设置或清 Key 会停止相关回答。后台中断时需重新选中文字，再点击操作条或通过右键菜单查阅。

## 词句收藏

翻译或解释生成完成后，点击结果卡的“收藏”。会一起保存选中文字、当前回答、已生成的双语例句或用法示例、所在语境及来源标题和链接。保存不调用模型；未完成的回答无法收藏。

同一来源网页中，原文相同且查阅方式相同的词句会更新已有条目。收藏后再补充例句，可点“更新收藏”；未重新生成例句的更新会保留已收藏的例句。翻译与解释分别保存。删除收藏后，原结果卡可直接重新收藏。

点击侧栏“收藏”标签进入管理页；结果卡的“收藏夹”和独立设置页入口也保留。支持按词句、回答、例句、语境和来源搜索，按翻译／解释筛选，展开查看语境、打开原文及确认后删除。按最近更新时间排序。支持导出全部或当前筛选结果为 JSON／Markdown，不包含 Key 和模型配置。当前不提供导入。

收藏保存在当前浏览器配置的 `chrome.storage.local`，重启浏览器后仍在。查看、搜索、导出和删除不需要模型 Key 或网站权限。没有云同步；卸载扩展或清除扩展数据会移除收藏，可先导出留存。最多 500 条或 6 MiB，达到上限会提示，不自动删除旧条目。存储错误时保留回答并允许重试保存。

## 跨页研究

点击侧栏“跨页研究”标签，输入一个具体问题，并逐行填写 1—5 个技术文章或文档的最终链接。点击“授权所填网站”完成域名授权；沿用“设置”中的模型接口与 Key。开始前会检查网站和模型接口权限。

开始后，扩展按输入顺序临时打开文档标签、读取已加载的可见正文，再关闭阅读标签。每页提取与问题有关的要点及连续原文引句，最后生成来源比较表、资料概览和带引用的比较结论。点击引用可定位原文证据，来源链接可另行打开核对。

每页最多一次模型分析，最后一次汇总，总计最多 6 次。任务状态显示实际调用次数，输入和授权不调用模型。只有通过原文引句检查的发现参与报告；部分失败会列出原因并说明报告范围，全部失败不生成完整报告。引句存在性与引用编号检查无法保证模型解释和比较语义绝对正确，请结合上下文判断。

研究任务页需保持打开；在侧栏切换到对话、收藏或设置标签会保留研究页面，任务继续运行。关闭所属页面或侧栏文档、手动停止、撤销权限或改变模型配置会停止任务。任务最长 12 分钟。超出设置的单次预算时提示失败，不静默截断正文，也不自动重试。后台中断会保留会话检查点并标注中断，不自动恢复模型请求。

首版只读取你提供的最终链接。发生跳转或导航时提示改用最终地址，未授权的新域不会读取；已改作其他用途的临时标签会保留。当前范围不含自主搜索、沿链接继续访问或填写网页表单。

完成后可手动保存到本机，或导出带比较表和引句的 Markdown。已存报告可在无 Key、无网站权限时查看、导出和确认删除，浏览器重启后仍保留。最多 20 份或 1.5 MiB，不自动淘汰旧报告。当前任务检查点保存在 session，已存报告保存在 local；不新增应用后端或云同步。

## 长文与读取范围

设置里的“单次上下文预算”默认 **64,000 tokens**，范围 2,048—128,000。预算包括系统说明、元信息、输入、输出预留及余量，应按所选模型能力填写。升级时保留已保存的预算。Token 数使用保守估算，具体计费由服务商决定。

- 预算内：提交全部已提取正文，生成一次摘要。
- 超预算：显示预计调用次数，点击确认后按原文顺序分段提取事实，再分层整合。可在设置中允许自动分段；默认不连续发起多次调用。
- 中途停止或失败：保留已收到的内容，标记摘要尚未完成；停止后不再发起后续调用，不自动重试。

提取会保留导语元信息，移除了旧版 24,000 字符的开头裁切。资源保护上限为 300,000 字符，达到上限时提示失败。动态网页可等待加载后点“重新读取”。

“全部已读取正文”指当前页面已加载、可见、可访问的内容。登录、验证码、付费墙、隐藏区、分页或尚未展开的正文可能导致范围不足，界面会尽可能提示。扩展不会自动跨页抓取或读取隐藏付费内容。摘要质量仍受抽取结果、模型与预算影响。

## 网页嵌入与权限

为支持真实网页的 iframe 预览，0.2.0 新增 `webNavigation` 和 `declarativeNetRequestWithHostAccess`。后者仅在预览期间，对来源标签页、来源主机及目标主机的 GET iframe 请求移除 `X-Frame-Options`。关闭、撤销权限及恢复后台时会清理或重新限定会话规则。

0.3.0 新增 `contextMenus`，用于原生右键的两个选区阅读菜单项。现有安装升级后需重新加载扩展并刷新网页。

0.6.0 新增 `sidePanel`，让工具栏图标打开浏览器原生侧栏。侧栏中的设置、研究和收藏只嵌入扩展自己打包的页面；没有新增必选网站访问权限。

网站的 CSP `frame-ancestors` 和其他访问策略仍可能阻止加载。此时界面说明原因，并提供“在标签页打开”。目标或跳转后的最终域未授权时，需先在设置中授权才能提取和摘要。

首次绑定会核对实际 iframe URL 与明确拖动的链接。若网站在绑定前已重定向到其他地址，摘要可能无法就绪，可在普通标签页打开，或拖动最终链接重试。已绑定预览内的后续导航会重置旧摘要。

## 本机数据与接口

- 设置保存在 `chrome.storage.local`；默认 Key 在 `chrome.storage.session`，选择“本机记住”才持久保存。持久 Key 未使用操作系统保险库加密。
- local/session 均限制为 `TRUSTED_CONTEXTS`。Key 不进入网页、内容脚本消息、URL、日志或设置导出。可在设置页清除 Key 与会话摘要缓存。
- 会话保存预览元数据、最多 20 项摘要缓存、当前研究任务检查点和直接聊天消息；聊天不会写入 local。仅在明确点击收藏或保存报告后持久保存对应内容。不使用 `storage.sync`、自建服务、账号、支付或统计上报。
- 聊天会把当前问题和已完成的历史轮次发送给所选模型连接；扩展不新增应用云端存储。官方订阅连接的长期凭证由助手用 Windows DPAPI 加密保存，访问令牌仅暂存在扩展后台内存，不写入扩展存储或诊断。旧网页连接允许记录留在 OpenAI，由官网页面环境中的客户端处理会话与请求校验，其登录凭据不传到扩展后台。各连接凭据相互隔离。远程模型服务商对收到的内容有自己的处理和保留规则。
- 总结会将提取后的正文、标题、导语及必要元信息发送到指定模型接口。长文处理还会向同一接口提交中间提要。来源页 DOM 内的界面可能被来源网站读取。
- 适配支持 `stream: true`、`store: false`、`max_tokens` 的 Chat Completions 文本服务。接口使用 HTTPS；本机模型和夹具可单独授权 `localhost` / `127.0.0.1` HTTP。请求禁止自动跟随重定向，无自动切换模型或付费重试。
- 停止会终止客户端连接，服务商的费用结算取决于所用接口。后台中断后需手动重试。

## 兼容边界

优先支持普通 HTTPS 文章、文档和外语内容。Chrome 内部页面、Chrome Web Store、PDF、视频、复杂编辑器、嵌套跨域 iframe、封闭 Shadow DOM 和图片正文不在本轮摘要范围。普通 HTTP 网站暂不支持。

真实网站兼容性、真实模型回答与摘要质量、用户 Chrome 原生工具栏打开及停靠侧栏、权限对话框、右键菜单和拖向标签栏体验属于人工检查范围。第一阶段已获用户整体验收确认；具体浏览器、接口和逐项人工测试结果未另行提供，自动化模拟证据保持原有记录。
